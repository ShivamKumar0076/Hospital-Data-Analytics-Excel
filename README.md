# 🏥 Hospital Data Analytics Dashboard — Excel

An interactive **Hospital Data Analytics Dashboard** built using **Microsoft Excel 2019** to analyze hospital admissions, billing, patient outcomes, departments, medical conditions, cities, and monthly admission trends.

The project follows a complete data analytics workflow:

**Raw Data → Data Cleaning → Data Validation → Pivot Analysis → Interactive Dashboard**

---

## 🎯 Project Objective

The objective of this project is to transform a messy hospital dataset into a structured and interactive Excel dashboard that can help analyze:

- Hospital admission patterns
- Department-wise admissions
- Medical-condition distribution
- Monthly admission trends
- Patient outcomes
- City-wise admissions
- Department-wise billing
- Average length of stay
- Patient satisfaction

---

## 🧹 Data Cleaning & Preparation

The raw dataset contained duplicates, missing values, inconsistent categories, mixed formats, and invalid date relationships.

The following cleaning and validation activities were performed:

- Removed exact duplicate records
- Standardized gender values
- Standardized city names
- Standardized department names
- Standardized medical-condition categories
- Standardized admission types
- Standardized doctor names
- Standardized insurance-provider values
- Standardized payment modes
- Standardized patient outcomes
- Cleaned billing amounts and converted them into numeric values
- Standardized admission and discharge date formats
- Cleaned length-of-stay values
- Handled missing age information without making assumptions
- Used `Unavailable`, `Unknown`, and `Not Provided` where appropriate instead of inventing information
- Identified discharge-date records requiring review
- Validated the cleaned dataset using Excel analysis

## 📈 Dashboard KPIs

The dashboard includes interactive KPI cards for:

| KPI | Description |
|---|---|
| **Admission** | Number of hospital admissions |
| **Billings** | Total billing amount |
| **Avg Stay** | Average patient length of stay |
| **Satisfaction** | Average available satisfaction score |

KPI values dynamically respond to the dashboard filters.

## 📊 Dashboard Visualizations

The dashboard contains:

### Admissions by Department
Shows the distribution of hospital admissions across departments.

### Admissions by Medical Condition
Shows admission counts across different medical conditions.

### Monthly Admissions Trend
Displays admission trends across the months of the year.

### Patient Outcome Distribution
Shows the distribution of patient outcomes using a doughnut chart.

### Admissions by City
Compares hospital admissions across different cities.

### Billing by Department
Analyzes billing generated across hospital departments.
